# finalTerm - 수강신청 시스템

## 기능

### 1. 검색 기능

- **과목 코드**: 과목 코드로 검색 (예: CS101)
- **과목명**: 과목명으로 검색 (예: 자료구조)
- **교수명**: 교수 이름으로 검색 (예: 김태현)
- 실시간 검색으로 입력하면서 바로 결과 업데이트

### 2. 필터 기능 (고급 필터)

필터 버튼을 클릭하면 다음 조건으로 필터링 가능:

- **시간 (요일)**: 월, 화, 수, 목, 금 중 선택
- **이수구분**: 교필, 교선, 전필, 전선 중 선택
- **학년**: 1학년, 2학년, 3학년, 4학년 중 선택
- **전공**: 컴퓨터공학, 소프트웨어, 데이터사이언스 등 중 선택

각 필터는 다중 선택(Multiple Select) 지원

### 3. 검색과 필터 결합

- 검색과 필터를 동시에 사용 가능
- 모든 조건을 만족하는 과목만 표시 (AND 조건)
- 초기화 버튼으로 모든 검색/필터 초기화

## 사용법

1. **검색하기**: 왼쪽 검색바에 과목 코드, 과목명, 또는 교수명 입력
2. **필터 적용하기**:
    - "고급 필터" 버튼 클릭
    - 원하는 필터 옵션 선택 (다중 선택 가능)
    - "적용" 버튼 클릭
3. **필터 초기화하기**:
    - 필터 모달에서 "초기화" 버튼 클릭
    - 또는 다시 "고급 필터" 버튼 클릭 후 "적용" (선택 안 함 상태)

## 기술 스택

- HTML5
- CSS3 (다크테마)
- JavaScript (Vanilla JS, no frameworks)

## 폴더 구조

```
.
├── index.html      # 메인 HTML 파일
├── script.js       # JavaScript 로직 (검색/필터 포함)
├── style.css       # 스타일시트

```

## 주요 함수

- `performSearch(query)`: 검색 수행
- `performFilter(filters)`: 필터 적용
- `applySearchAndFilter()`: 검색과 필터 결합하여 결과 표시
- `openFilterModal()`: 필터 모달 열기
- `closeFilterModal()`: 필터 모달 닫기
- `resetFilters()`: 모든 필터 초기화
